# 💌 เว็บบอกรักแฟนฉบับพิเศษ (Interactive Love Letter)

โปรเจกต์เว็บแอปพลิเคชันบอกรักแฟนสุดโรแมนติก พร้อมอนิเมชันเปิดซองจดหมาย 3D, เอฟเฟกต์พลุหัวใจพุ่งกระจาย (Heart Burst Confetti), แกลเลอรีรูปภาพสไตล์โพลารอยด์ (Polaroid Memories) และเสียงเพลงบรรเลงประกอบ

---

### ✨ ฟีเจอร์เด่นในเว็บนี้
1. **ซองจดหมาย 3D & ตราประทับขี้ผึ้ง (Wax Seal)**
   - เมื่อกดที่ตราประทับหรือตัวซอง จะมีเสียง Chime เพราะๆ
   - ฝาซองเปิดออกในรูปแบบ 3D พร้อมตัวจดหมายค่อยๆ เลื่อนขึ้นมา
2. **เอฟเฟกต์หัวใจระเบิด (Heart Burst Fireworks)**
   - อนุภาคหัวใจฟุ้งกระจายเต็มหน้าจอเมื่อเปิดจดหมาย
   - มีหัวใจลอยขึ้นมาจากด้านล่างตลอดเวลา
   - คลิกหรือแตะตรงไหนบนหน้าจอก็มีหัวใจเด้งออกมา
3. **ข้อความบอกรักสุดซึ้ง**
   - ข้อความตรงตามที่คุณต้องการ จัดวางฟอนต์ภาษาไทยอย่างสวยงาม เน้นประโยคกินใจ
4. **แกลเลอรีรูปภาพโพลารอยด์ 5 รูป**
   - ใส่รูปที่คุณส่งมาทั้งหมด 5 รูป (`photo1.jpg` - `photo5.webp`) พร้อมเอฟเฟกต์เทปแปะและการเอียงมุมแบบน่ารัก
   - สามารถคลิกที่รูปเพื่อเปิดดูแบบขยายใหญ่เต็มจอ (Lightbox) ได้
5. **ปุ่มอินเตอร์แอคทีฟ**
   - **ปุ่ม "ส่งหัวใจให้พี่"**: กดรัวๆ ได้ มีตัวนับจำนวนครั้งและหัวใจพุ่งขึ้นจากปุ่ม
   - **ปุ่ม "เกี่ยวก้อยสัญญานะ"**: กดแล้วมีหน้าต่างป๊อปอัปสัญญาสุดน่ารักเด้งขึ้นมา
6. **เสียงเพลงบรรเลง (Romantic Sound Synthesizer)**
   - มีปุ่มเปิด/ปิดเพลงมุมขวาบน ทำงานผ่าน Web Audio API ไม่ต้องต่อเน็ตหรือโหลดไฟล์เพลงภายนอก

### 🚀 วิธีเปิดใช้งาน
1. เข้าไปที่โฟลเดอร์ `code love` บนหน้าจอ Desktop ของคุณ
2. **ดับเบิลคลิกที่ไฟล์ `index.html`** จะเปิดขึ้นมาบนบราวเซอร์ (Chrome / Edge / Safari / Firefox) ได้ทันที!
3. รองรับทั้งบนคอมพิวเตอร์และบนหน้าจอมือถือ (Responsive Design)
